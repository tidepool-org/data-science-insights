# loop_settings_distribution — Project history

## 2026-10-05: subproject created; exploratory settings-distribution probe written

- **Ask (MC).** A separate folder under the insights repository for the distribution of therapy settings (ISF, CR, BR) among Loop users as the FDA work defines them, for the pediatric 6-11 group and every other age group; start with an exploratory script.
- **Design decisions taken (Claude; stated here for MC to confirm or overturn).** (1) Population = confirmed type-1 Loop users, the `rfai_t1_users` view copied verbatim from `FDA_real_world_data/exploratory/rfai_insulin_type_by_age.sql`. (2) The version gate (Loop < 3.4.0, date fallback 2024-07-13) and the age gate (6 or older, or DOB unknown) are applied to each `pumpSettings` record on its own day, using the record's own `origin.version`; result 0 shows what each gate removes so the choice can be reversed from the numbers. (3) Age bands are analysis 8-5's (6-11, 12-17, 18-64, 65+) plus 'age unknown', by completed years on the record's day; a user observed in two bands contributes one observation to each (result 6 counts them). (4) One record per (user, settings time), latest `created_timestamp` wins (the correction-range staging's rule). (5) The record's schedule per setting follows the correction-range staging's fallback chain: `activeSchedule` → 'Default' → first non-empty named schedule → singular column; result 2 reports which branch fired. (6) ISF converts to mg/dL per U with 18.016 (the guardrail staging's constant) unless `units.bg` reads 'mg/dL'; result 2b lists the units vocabulary. (7) No carry-forward across partial uploads: a null schedule contributes no entries (a day-weighted settings-in-force variant is a possible follow-up). (8) Primary grain = per-user observation: the median of a user's entries within an age band, with min and max kept; the entry-level view is reported too, labelled as record- and slot-weighted. (9) A scheduled basal total per record (U/day) is derived from the chosen basal schedule when every slot is complete and the schedule starts at midnight. (10) Small-subgroup rule throughout.
- **Decision (MC, same day).** No transliteration of Arabic-Indic digits in `bddp_user_dates.dob`: the date of birth is cast tolerantly and a value that does not cast counts as age unknown. The by-age file's `TRANSLATE` rule is deliberately not copied; the offline test now asserts its absence.
- **Written.** `exploratory/loop_settings_distribution_probe.sql` (results 0–7, one scratch table `dev.fda_510k_rwd.lsd_settings_records` dropped first and last), `run_settings_probes.py` (Run-button driver reusing the FDA exporter), `testing/test_settings_probes.py` (eleven offline checks, all passing locally), `outputs/.gitkeep`; `.gitignore` entry for `outputs/`; row added to the repo-root `CLAUDE.md` table.
- **Not run.** No Databricks run yet; no number exists. Two constants in the repository convert mmol/L to mg/dL (18.016 in the guardrail staging, 18.018 in the correction-range staging); the probe uses the guardrail staging's because ISF is a guardrail quantity. The difference is 0.01% and immaterial to any reported percentile.
